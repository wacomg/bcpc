1.1 CONTROL WORD (0X6040)
--------------------------------------------------------------------------------
Назначение: Управление состоянием усилителя, запуск/остановка перемещений,
             сброс ошибок.
Тип: Unsigned 16
Доступ: Чтение/Запись
Отображение в PDO: EVENT

СТРУКТУРА БИТОВ:
+----------+---------------------------------------------------------+
| Бит      | Название            | Описание                              |
+----------+---------------------+---------------------------------------+
| 0        | Switch On           | Должен быть 1 для включения           |
| 1        | Enable Voltage      | Должен быть 1 для включения           |
| 2        | Quick Stop          | 0 = быстрая остановка                 |
| 3        | Enable Operation    | Должен быть 1 для включения           |
| 4        | New Setpoint        | 0->1 = запуск нового перемещения      |
| 5        | Change Set          | 1 = немедленное изменение параметров  |
|          | Immediately         |     во время движения                 |
| 6        | Absolute/Relative   | 0 = абсолютное, 1 = относительное     |
| 7        | Reset Fault         | 0->1 = сброс ошибки                   |
| 8        | Halt                | 1 = остановка                         |
| 9-15     | Reserved            | Зарезервировано                       |
+----------+---------------------+---------------------------------------+

ПРИМЕРЫ КОМАНД:
  Включение усилителя:         0x000F (биты 0,1,2,3 = 1)
  Включение с запуском движения: 0x001F (биты 0,1,2,3,4 = 1)
  Быстрая остановка:           0x000B (бит 2 = 0)
  Остановка (Halt):            0x010F (бит 8 = 1)
  Сброс ошибки:                0x008F (бит 7 = 1, затем 0x000F)

2.1 NMT КОМАНДЫ
--------------------------------------------------------------------------------
NMT сообщение структура: COB-ID = 0, 2 байта данных

+----------+---------------------+---------------------------------------------+
| Команда  | Код                 | Описание                                    |
+----------+---------------------+---------------------------------------------+
| Start    | 0x01                | Переход в Operational (запуск узла)         |
| Stop     | 0x02                | Переход в Stopped (остановка узла)          |
| Pre-op   | 0x80                | Переход в Pre-operational                   |
| Reset    | 0x81                | Сброс приложения (перезапуск узла)          |
| Reset    | 0x82                | Сброс сетевых установок                     |
| Comm     |                     |                                             |
+----------+---------------------+---------------------------------------------+

Второй байт: Node ID (0 = широковещательная команда всем узлам).

Примеры:
  Запуск узла 5:        0x01 0x05
  Широковещательный запуск: 0x01 0x00
  Сброс узла 3:         0x81 0x03


2.2 СОСТОЯНИЯ УСТРОЙСТВА
--------------------------------------------------------------------------------
+------------------+---------------------------------------------------------+
| Состояние        | Описание                                                |
+------------------+---------------------------------------------------------+
| Not Ready to     | Инициализация, низкое напряжение                        |
| Switch On        |                                                         |
+------------------+---------------------------------------------------------+
| Switch On        | Инициализация завершена, параметры доступны             |
| Disabled         |                                                         |
+------------------+---------------------------------------------------------+
| Ready to         | Готов к включению, параметры доступны                   |
| Switch On        |                                                         |
+------------------+---------------------------------------------------------+
| Switched On      | Высокое напряжение подано, выход отключён               |
+------------------+---------------------------------------------------------+
| Operation Enable | Нормальная работа, выход включён                        |
+------------------+---------------------------------------------------------+
| Quick Stop       | Выполняется быстрая остановка                           |
| Active           |                                                         |
+------------------+---------------------------------------------------------+
| Fault Reaction   | Реакция на ошибку                                       |
| Active           |                                                         |
+------------------+---------------------------------------------------------+
| Fault            | Ошибка, выход отключён                                  |
+------------------+---------------------------------------------------------+


2.3 HEARTBEAT И NODE GUARDING
--------------------------------------------------------------------------------

HEARTBEAT PRODUCER HEARTBEAT TIME (0X1017):
  Назначение: Период отправки Heartbeat сообщений.
  Тип: Unsigned 16
  Значение: 0 = отключено, иначе период в мс.

Heartbeat сообщение: COB-ID = 0x700 + Node ID, 1 байт состояния.
  Состояние: 0x04 = Stopped, 0x05 = Operational, 0x7F = Pre-operational

CONSUMER HEARTBEAT TIME (0X1016):
  Назначение: Контрольное время для приёма Heartbeat.
  Под-индекс 1: 32-бита (биты 0-15 = время в мс, биты 16-23 = Node ID)

GUARD TIME (0X100C):
  Назначение: Период опроса узла.
  Тип: Unsigned 16
  Значение: 0 = отключено, иначе период в мс.

LIFE TIME FACTOR (0X100D):
  Назначение: Множитель для Guard Time.
  Тип: Unsigned 8
  Контрольное время = Guard Time * Life Time Factor

3.1 PROFILE POSITION MODE (РЕЖИМ 1)
--------------------------------------------------------------------------------
Назначение: Перемещение из точки в точку с заданными параметрами профиля.

ОСНОВНЫЕ ОБЪЕКТЫ:
+----------+---------------------+---------------------------------------------+
| Индекс   | Название            | Описание                                    |
+----------+---------------------+---------------------------------------------+
| 0x607A   | Target Position     | Целевая позиция (в отсчётах)                |
| 0x6081   | Profile Velocity    | Скорость профиля (0.1 отсчётов/сек)         |
| 0x6083   | Profile Acceleration| Ускорение профиля (10 отсчётов/сек²)        |
| 0x6084   | Profile Deceleration| Замедление профиля (10 отсчётов/сек²)       |
| 0x6086   | Motion Profile Type | Тип профиля: 0=трапеция, 3=S-кривая, -1=vel |
| 0x2121   | Trajectory Jerk     | Ограничение рывка (для S-кривой)            |
|          | Limit               |                                             |
+----------+---------------------+---------------------------------------------+

Motion Profile Type (0x6086):
  0  = Trapezoidal (трапециедальный)
  3  = S-curve (S-кривая, ограничение рывка)
  -1 = Velocity mode (специальный режим, бесконечное движение)

БИТЫ CONTROL WORD (0X6040):
  Бит 4 = New Setpoint (0->1 для запуска)
  Бит 5 = Change Set Immediately (1 = немедленное обновление)
  Бит 6 = Absolute/Relative (0=абсолютное, 1=относительное)

+----------+---------------------+---------------------------------------------+
| 0x60C0   | Interpolation       | Выбор подрежима: 0=const time, -1=var time, |
|          | Submode Select      | -2=PVT                                      |
| 0x60C1-1 | Interpolation       | Целевая позиция                             |
|          | Position Target     |                                             |
| 0x60C1-2 | Interpolation Time  | Время сегмента (для var time и PVT)         |
| 0x60C1-3 | Interpolation       | Скорость (для PVT)                          |
|          | Velocity            |                                             |
| 0x60C2-1 | Interpolation       | Постоянное время (для submode 0)            |
|          | Constant Time       |                                             |
+----------+---------------------+---------------------------------------------+

АЛЬТЕРНАТИВНЫЕ ОБЪЕКТЫ DCH (БОЛЕЕ ЭФФЕКТИВНЫЕ):
+----------+---------------------+---------------------------------------------+
| Индекс   | Название            | Описание                                    |
+----------+---------------------+---------------------------------------------+
| 0x2010   | IP move segment     | Команда сегмента (8 байт)                   |
|          | command             |                                             |
| 0x2011   | Trajectory Buffer   | Свободных мест в буфере                     |
|          | Free Count          |                                             |
| 0x2012   | Trajectory Buffer   | Статус буфера (32 бита)                     |
|          | Status              |                                             |
| 0x2013   | Next Trajectory     | ID следующего ожидаемого сегмента           |
|          | Segment ID          |                                             |
+----------+---------------------+---------------------------------------------+

ФОРМАТ 0x2010 (байт 0):
  Бит 7 = 1: Команда управления буфером
    Команды: 0=очистить буфер, 1=извлечь N сегментов, 2=очистить ошибки
  Бит 7 = 0: PVT сегмент
    Биты 0-2: Счётчик целостности (0-7)
    Биты 3-6: Формат данных (0-7)


3.6 CYCLIC SYNCHRONOUS POSITION (РЕЖИМ 8, CSP)
--------------------------------------------------------------------------------
Назначение: Позиция задаётся синхронно из ведущего устройства.

ОСНОВНЫЕ ОБЪЕКТЫ:
+----------+---------------------+---------------------------------------------+
| Индекс   | Название            | Описание                                    |
+----------+---------------------+---------------------------------------------+
| 0x607A   | Target Position     | Целевая позиция                             |
| 0x60FF   | Target Velocity     | Целевая скорость (feedforward)              |
| 0x6071   | Target Torque       | Целевой момент (feedforward)                |
+----------+---------------------+---------------------------------------------+

Все три контура (положения, скорости, тока) замкнуты в усилителе.


3.7 CYCLIC SYNCHRONOUS VELOCITY (РЕЖИМ 9, CSV)
--------------------------------------------------------------------------------
Назначение: Скорость задаётся синхронно из ведущего устройства.

ОСНОВНЫЕ ОБЪЕКТЫ:
+----------+---------------------+---------------------------------------------+
| Индекс   | Название            | Описание                                    |
+----------+---------------------+---------------------------------------------+
| 0x60FF   | Target Velocity     | Целевая скорость                             |
| 0x6071   | Target Torque       | Целевой момент (feedforward)                |
+----------+---------------------+---------------------------------------------+

Контуры скорости и тока замкнуты в усилителе.


3.8 CYCLIC SYNCHRONOUS TORQUE (РЕЖИМ 10, CST)
--------------------------------------------------------------------------------
Назначение: Момент задаётся синхронно из ведущего устройства.

ОСНОВНЫЕ ОБЪЕКТЫ:
+----------+---------------------+---------------------------------------------+
| Индекс   | Название            | Описание                                    |
+----------+---------------------+---------------------------------------------+
| 0x6071   | Target Torque       | Целевой момент                              |
+----------+---------------------+---------------------------------------------+

Только контур тока замкнут в усилителе.


================================================================================
4. КОМАНДЫ ДЛЯ ПЕРЕМЕЩЕНИЙ
================================================================================

4.1 ЗАПУСК ПЕРЕМЕЩЕНИЯ В PROFILE POSITION MODE
--------------------------------------------------------------------------------
ПОСЛЕДОВАТЕЛЬНОСТЬ:
  1. Установить Mode Of Operation = 1 (0x6060)
  2. Установить Target Position (0x607A)
  3. Установить Profile Velocity (0x6081)
  4. Установить Profile Acceleration (0x6083)
  5. Установить Profile Deceleration (0x6084) (только для трапеции)
  6. Установить Motion Profile Type (0x6086): 0=трапеция, 3=S-кривая
  7. Установить Control Word бит 4 = 1 (запуск)

ПРИМЕР (абсолютное перемещение на 1000 отсчётов):
  Запись 0x01 в 0x6060           (режим Profile Position)
  Запись 1000 в 0x607A           (целевая позиция)
  Запись 5000 в 0x6081           (скорость 500 отсч/сек)
  Запись 10000 в 0x6083          (ускорение 1000 отсч/сек²)
  Запись 10000 в 0x6084          (замедление 1000 отсч/сек²)
  Запись 0x001F в 0x6040         (включить и запустить)


4.2 ЗАПУСК ПЕРЕМЕЩЕНИЯ В PROFILE VELOCITY MODE
--------------------------------------------------------------------------------
ПОСЛЕДОВАТЕЛЬНОСТЬ:
  1. Установить Mode Of Operation = 3 (0x6060)
  2. Установить Target Velocity (0x60FF)
  3. Установить Profile Acceleration (0x6083)
  4. Установить Profile Deceleration (0x6084)
  5. Control Word бит 8 = 0 (отмена Halt, если был)

ПРИМЕР (скорость 1000 отсч/сек):
  Запись 0x03 в 0x6060
  Запись 1000 в 0x60FF
  Запись 5000 в 0x6083
  Запись 5000 в 0x6084
  Запись 0x000F в 0x6040         (включить)


4.3 ЗАПУСК ПЕРЕМЕЩЕНИЯ В PROFILE TORQUE MODE
--------------------------------------------------------------------------------
ПОСЛЕДОВАТЕЛЬНОСТЬ:
  1. Установить Mode Of Operation = 4 (0x6060)
  2. Установить Target Torque (0x6071)
  3. Установить Torque Slope (0x6087)
  4. Control Word бит 8 = 0


4.4 ЗАПУСК ПОИСКА НУЛЯ (HOMING)
--------------------------------------------------------------------------------
ПОСЛЕДОВАТЕЛЬНОСТЬ:
  1. Установить Mode Of Operation = 6 (0x6060)
  2. Установить Homing Method (0x6098)
  3. Установить Homing Speeds (0x6099-1 и 0x6099-2)
  4. Установить Homing Acceleration (0x609A)
  5. Установить Control Word бит 4 = 1 (запуск)

ОКОНЧАНИЕ ПОИСКА НУЛЯ:
  Status Word бит 12 = 1 (Homing attained)
  Status Word бит 13 = 0 (нет ошибки)


4.5 ЗАПУСК ИНТЕРПОЛИРОВАННОГО ПЕРЕМЕЩЕНИЯ
--------------------------------------------------------------------------------
ПОСЛЕДОВАТЕЛЬНОСТЬ (с использованием DCH альтернативных объектов):
  1. Установить Mode Of Operation = 7 (0x6060)
  2. Настроить PDO для 0x2010 (IP move segment command)
  3. Настроить PDO для 0x2012 (Trajectory Buffer Status)
  4. Заполнить буфер через 0x2010 (8-байтовые сегменты)
  5. Установить Control Word бит 4 = 1 (запуск)
  6. Следить за 0x2012 для поддержания буфера заполненным


4.6 ОСТАНОВКА ПЕРЕМЕЩЕНИЯ
--------------------------------------------------------------------------------
СПОСОБЫ ОСТАНОВКИ:
+----------+---------------------+---------------------------------------------+
| Способ   | Действие            | Описание                                    |
+----------+---------------------+---------------------------------------------+
| Quick    | Бит 2 Control Word  | Быстрая остановка по заданному замедлению   |
| Stop     | = 0                 |                                             |
| Halt     | Бит 8 Control Word  | Остановка по заданному замедлению           |
|          | = 1                 |                                             |
| Disable  | Бит 3 Control Word  | Отключение работы (мгновенная остановка)    |
|          | = 0                 |                                             |
| Shutdown | Бит 0 Control Word  | Выключение (мгновенная остановка)           |
|          | = 0                 |                                             |
+----------+---------------------+---------------------------------------------+

НАСТРОЙКА РЕЖИМОВ ОСТАНОВКИ:
  Quick Stop Option Code (0x605A):
    0 = отключить выходы
    1 = замедление по Profile Deceleration
    2 = замедление по Quick Stop Deceleration
    3 = резкая остановка
    5 = замедление и остаться в Quick Stop

  Halt Option Code (0x605D):
    0 = отключить выходы
    1 = замедление по Profile Deceleration
    2 = замедление по Quick Stop Deceleration
    3 = резкая остановка


4.7 ИЗМЕНЕНИЕ ПАРАМЕТРОВ ВО ВРЕМЯ ДВИЖЕНИЯ
--------------------------------------------------------------------------------
УСЛОВИЯ:
  - Только в режиме Profile Position
  - Только трапециедальный профиль (Motion Profile Type = 0)

ПОСЛЕДОВАТЕЛЬНОСТЬ:
  1. Изменить нужные параметры (Target Position, Velocity, и т.д.)
  2. Установить Control Word бит 5 = 1 (Change Set Immediately)
  3. Установить Control Word бит 4 = 1 (New Setpoint)

5. КОМАНДЫ ДЛЯ PDO
================================================================================

5.1 ПРИЁМНЫЕ PDO (RXPDO)
--------------------------------------------------------------------------------
ПАРАМЕТРЫ СВЯЗИ (0X1400 - 0X1407):
  Под-индекс 1 (PDO COB-ID): CAN идентификатор
  Под-индекс 2 (PDO Type): Тип передачи (0-240=синхр., 254-255=асинхр.)

ОТОБРАЖЕНИЕ (0X1600 - 0X1607):
  Под-индекс 0: Количество отображённых объектов
  Под-индекс 1-8: 32-битные значения отображения

ФОРМАТ ЗНАЧЕНИЯ ОТОБРАЖЕНИЯ:
  Биты 0-7: Размер объекта в битах (0x08, 0x10, 0x20)
  Биты 8-15: Под-индекс объекта
  Биты 16-31: Индекс объекта

ПРИМЕР: Отображение Control Word (0x6040) и Mode Of Operation (0x6060)
  Под-индекс 0 = 2
  Под-индекс 1 = 0x60400010
  Под-индекс 2 = 0x60600008

ЗАДАННЫЕ ОТОБРАЖЕНИЯ:
  0x1700 (RxPDO, только чтение):
    Под-индекс 1: 0x60400010 (Control Word)
    Под-индекс 2: 0x607A0020 (Target Position)
    Под-индекс 3: 0x60B10020 (Velocity Offset)
    Под-индекс 4: 0x60B20010 (Torque Offset)

  0x1701 (RxPDO, только чтение):
    Под-индекс 1: 0x60400010 (Control Word)
    Под-индекс 2: 0x60FF0020 (Target Velocity)
    Под-индекс 3: 0x60B20010 (Torque Offset)

  0x1702 (RxPDO, только чтение):
    Под-индекс 1: 0x60400010 (Control Word)
    Под-индекс 2: 0x60710010 (Target Torque)


5.2 ПЕРЕДАЮЩИЕ PDO (TXPDO)
--------------------------------------------------------------------------------
ПАРАМЕТРЫ СВЯЗИ (0X1800 - 0X1807):
  Под-индекс 1 (PDO COB-ID): CAN идентификатор
  Под-индекс 2 (PDO Type): Тип передачи

ОТОБРАЖЕНИЕ (0X1A00 - 0X1A07):
  Под-индекс 0: Количество отображённых объектов
  Под-индекс 1-8: 32-битные значения отображения

ЗАДАННЫЕ ОТОБРАЖЕНИЯ (0X1B00, только чтение):
  Под-индекс 1: 0x60400010 (Control Word)
  Под-индекс 2: 0x60640020 (Actual Position)
  Под-индекс 3: 0x60F40020 (Position Error)
  Под-индекс 4: 0x606C0020 (Actual Velocity)
  Под-индекс 5: 0x60770010 (Actual Torque)


5.3 ОТОБРАЖЕНИЕ PDO (PDO MAPPING)
--------------------------------------------------------------------------------
ОБЩАЯ ПРОЦЕДУРА:
  1. Установить под-индекс 0 = 0 (отключить PDO)
  2. Настроить параметры связи (COB-ID, тип передачи)
  3. Записать значения отображения в под-индексы 1-8
  4. Установить под-индекс 0 = количество объектов (включить PDO)

БИТ 31 В COB-ID:
  0 = PDO активен
  1 = PDO отключён (можно изменять отображение)


5.4 ТИПЫ ПЕРЕДАЧИ PDO
--------------------------------------------------------------------------------
+----------+---------------------+---------------------------------------------+
| Код      | Тип                 | Описание                                    |
+----------+---------------------+---------------------------------------------+
| 0        | Синхронный,         | Передача по событию, но после SYNC          |
|          | ациклический        |                                             |
| 1-240    | Синхронный,         | Передача каждые N SYNC сообщений            |
|          | циклический         |                                             |
| 252      | Синхронный, по RTR  | Передача после SYNC по удалённому запросу   |
| 253      | Асинхронный, по RTR | Передача немедленно по удалённому запросу   |
| 254-255  | Асинхронный, по     | Передача по событию (изменение значения)    |
|          | событию             |                                             |
+----------+---------------------+---------------------------------------------+

8.2 КОНФИГУРАЦИЯ СЕТИ CANOPEN
--------------------------------------------------------------------------------
CANOPEN NETWORK CONFIGURATION (0X21B0):
  Биты 0-6: Смещение Node ID
  Биты 8-10: Количество входных выводов для Node ID (0-7)
  Биты 12-15: Скорость передачи

СКОРОСТЬ ПЕРЕДАЧИ:
  0 = 1 Мбит/с, 1 = 800 кбит/с, 2 = 500 кбит/с, 3 = 250 кбит/с
  4 = 125 кбит/с, 5 = 50 кбит/с, 6 = 20 кбит/с

INPUT MAPPING FOR CAN NODE ID (0X21B1):
  Биты 0-27: Отображение входных выводов на биты Node ID
  Бит 31: 1 = использовать это отображение

CAN ID SELECTION SWITCH VALUE (0X2197):
  Текущее состояние переключателя адреса CAN (0-15)


8.3 КОНФИГУРАЦИЯ ВХОДОВ/ВЫХОДОВ
--------------------------------------------------------------------------------
INPUT PIN CONFIGURATION (0X2192, под-индексы 1-N):
  Коды функций для каждого входа:
    0 = нет функции
    2 = сброс по переднему фронту
    3 = сброс по заднему фронту
    4 = положительный концевой выключатель (активный высокий)
    5 = положительный концевой выключатель (активный низкий)
    6 = отрицательный концевой выключатель (активный высокий)
    7 = отрицательный концевой выключатель (активный низкий)
    8 = датчик температуры двигателя (активный высокий)

    11 = отключение при низком уровне, сброс при переходе
    14 = концевой выключатель поиска нуля (активный высокий)
    15 = концевой выключатель поиска нуля (активный низкий)
    16 = отключение при высоком уровне
    17 = отключение при низком уровне
    20 = остановка при высоком уровне
    21 = остановка при низком уровне

--------------------------------------------------------------------------------

  2. Запись 1 в соответствующий бит Latching Fault Status Register (0x2183)
  3. NMT Reset или Reset Communication

LATCHING FAULT STATUS REGISTER (0X2183):
  Чтение: показывает активные фиксирующие ошибки
  Запись: очищает соответствующие ошибки (запись 1 в бит)
  Запись 0xFFFFFFFF: очистить все ошибки

12.2 НАСТРОЙКА ВХОДОВ
--------------------------------------------------------------------------------
INPUT PIN CONFIGURATION (0X2192):

  Под-индекс 1-N: настройка каждого входа

ДОСТУПНЫЕ ФУНКЦИИ:
  0  = нет функции
  2  = сброс по переднему фронту
  3  = сброс по заднему фронту
  4  = положительный концевой (активный высокий)
  5  = положительный концевой (активный низкий)
  6  = отрицательный концевой (активный высокий)
  7  = отрицательный концевой (активный низкий)
  8  = датчик температуры (активный высокий)
  9  = датчик температуры (активный низкий)
  10 = отключение при высоком, сброс при переходе
  11 = отключение при низком, сброс при переходе
  14 = концевой поиска нуля (активный высокий)
  15 = концевой поиска нуля (активный низкий)
  16 = отключение при высоком уровне
  17 = отключение при низком уровне
  20 = остановка при высоком уровне
  21 = остановка при низком уровне
  24 = захват позиции по переднему фронту (высокоскоростной)
  25 = захват позиции по заднему фронту (высокоскоростной)

INPUT PIN DEBOUNCE VALUES (0X2195):

    1 = по переднему фронту
    2 = по уровню (высокий)
    3 = по индексу энкодера

CAM DELAY FORWARD (0X2361): Задержка при прямом движении
CAM DELAY REVERSE (0X2362): Задержка при обратном движении
CAM MASTER VELOCITY (0X2363): Скорость виртуального ведущего энкодера


13.4 КОМАНДЫ ПОСЛЕДОВАТЕЛЬНОГО ПОРТА ЧЕРЕЗ CANOPEN
--------------------------------------------------------------------------------
SERIAL PORT COMMAND SEND (0X2000):
  Используется для отправки последовательных команд через CANopen

ФОРМАТ КОМАНДЫ:
  Первый байт = код команды
  Последующие байты = данные

ПРИМЕР (чтение фактической позиции):
  Запись: 0x0C 0x17 0x00
  Ответ: 0x00 0x34 0x12 0x78 0x56 (позиция 0x12345678)

ПОРЯДОК БАЙТОВ (32-битные значения):
  Сначала старшее слово, затем младшее
  Внутри слова: сначала младший байт, затем старший
  Пример: 0x12345678 -> 0x34 0x12 0x78 0x56

14. КОМАНДЫ ДЛЯ СОХРАНЕНИЯ ПАРАМЕТРОВ
================================================================================

STORE PARAMETERS (0X1010):
  Под-индекс 1: Сохранить все объекты
  Под-индекс 2: Сохранить параметры связи (0x1000-0x1FFF)
  Под-индекс 3: Сохранить параметры профиля (0x6000-0x9FFF)
  Под-индекс 4: Сохранить параметры производителя (0x2000-0x5FFF)

КЛЮЧЕВОЕ СЛОВО:
  Запись строки "save" (0x65766173) в под-индекс 1

СОХРАНЯЕМЫЕ ОБЪЕКТЫ:
  Параметры связи: 100C, 100D, 1015, 1016, 1017, 1029, 1800, 1801, 2100, 2101, 2800, 2801
  Параметры приложения: 6000, 6509

RESTORE DEFAULT PARAMETERS (0X1011):
  Под-индекс 1: Восстановить все параметры по умолчанию
  Ключевое слово: "load" (0x64616F6C)


================================================================================
15. КОМАНДЫ ДЛЯ ИНСТРУМЕНТА ТРАССИРОВКИ (TRACE TOOL)
================================================================================

TRACE CHANNELS (0X2500, под-индексы 1-6):
  Настройка до 6 каналов трассировки
  Коды переменных: 3=ток A, 4=ток B, 6=напряжение шины, 23=скорость,
                    28=позиция нагрузки, 31=позиция энкодера, и т.д.

TRACE STATUS (0X2501):
  Бит 0: идёт сбор данных
  Бит 1: триггер сработал

TRACE PERIOD (0X2505): Период сэмплирования (кратно базовому)
TRACE SAMPLE COUNT (0X2503): Количество собранных сэмплов
TRACE MAX SAMPLES (0X2504): Максимальное количество сэмплов

TRACE TRIGGER CONFIGURATION (0X2506):
  Биты 0-3: Номер канала для триггера
  Биты 8-11: Тип триггера
    0 = нет триггера
    1 = >= уровня
    2 = <= уровня
    3 = переход снизу вверх
    4 = переход сверху вниз
    5 = любой установленный бит
    6 = любой очищенный бит
    7 = любое изменение
  Бит 15: один сэмпл на событие

TRACE DELAY (0X2507): Задержка триггера (в периодах трассировки)
TRACE START/STOP (0X2508): 0=стоп, ненулевое=старт
TRACE DATA (0X2509): Чтение данных трассировки
